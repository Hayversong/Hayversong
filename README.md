## 🎯 Como eu gosto de trabalhar

- **Entender antes de usar:** prefiro saber como a ferramenta funciona por baixo.
- **Projetos de ponta a ponta:** da modelagem dos dados à tela final.
- **Código claro e organizado:** camadas bem definidas e fácil de manter.
- **Aprender construindo:** cada estudo vira um projeto de verdade.
